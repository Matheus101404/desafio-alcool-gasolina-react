# Desafio: Álcool ou Gasolina

Aplicação desenvolvida em React para cálculo de custo-benefício entre abastecer com álcool ou gasolina, com base na regra prática de 70%.

## 🚀 Tecnologias
- React
- Vite
- JavaScript / CSS

## 💻 Como executar
1. Clone o repositório
2. Instale as dependências: `npm install`
3. Execute o projeto: `npm run dev`
